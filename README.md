# 居家安全 · 防拐骗语音演练

一个给小学生用的交互式防拐骗演练网页。孩子独自在家时，会模拟三种上门场景（邻居王奶奶、快递员、修水管工人），孩子用打字或语音回答，AI 角色会根据回答推进剧情，最后给出防范评价。

## 在线访问

打开本仓库启用 GitHub Pages 后的网址即可，无需安装任何软件。

> 推荐使用 **Microsoft Edge** 浏览器打开。
> Chrome 在国内无法完成语音识别（麦克风说话），但打字回答完全正常。

### 关于大模型 API Key

- 每次打开网页会自动弹出「接入大模型」窗口。
- 在火山引擎方舟（豆包）平台申请自己的 API Key 和推理接入点 ID，填进去点「连接大模型」即可启用 AI 动态对话。
- **Key 不会保存在浏览器里**，关闭标签页或刷新后自动清空，下次打开需要重新填写。
- 不想用大模型就点「跳过」，用内置的本地话术演练，流程同样完整。

> 注意：本页面是浏览器直连方舟接口，若浏览器控制台报 CORS 错误，说明方舟未对当前 Pages 域名开放跨域，需要自行加一个转发代理。

## 使用说明

1. 打开网页后，点一下屏幕任意位置开始播放声音（浏览器要求先有一次点击）。
2. 选择一个场景（王奶奶 / 快递员 / 维修工）。
3. 听完敲门声和角色开场白后，用打字或麦克风回答对方。
4. 说出"报警 / 叫家长 / 看证件 / 视频通话"等警惕词，会立刻触发"成功防范"结算。

## 本地运行

本目录是纯静态文件，无需服务器。双击 `index.html` 即可在浏览器中体验；
此时麦克风不可用（浏览器安全策略），但可以打字回答，所有预录语音都能正常播放。

## 目录结构

```
├── index.html      网页本体（图片、样式、脚本全部内嵌）
├── audio/          18 个 MP3：1 个敲门声 + 17 段角色预录台词
└── .nojekyll      （GitHub Pages 用，请勿删除）
```

## 关于语音

- 三个角色的**固定台词**（开场白、标准应答、兜底、撤退）由 `audio/` 下的 MP3 播放，音质稳定。
- 学生回答后 AI 实时生成的那句话，在线版由浏览器内置语音朗读；
  如需更自然的真人音色，需在本地运行配套的 Edge TTS 服务（见原始开发文档）。
