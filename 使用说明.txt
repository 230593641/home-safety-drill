居家安全 · 防拐骗语音演练 —— 完整文件夹使用说明
==================================================

这个文件夹就是全部内容：一个网页 + 18 个语音文件 + 本地课堂增强脚本。
整个文件夹一起拷贝、一起上传，缺任何一样都没声音。

一、文件夹里都有什么
  index.html        网页本体（图片已内嵌，双击就能打开）
  audio/            全部语音，共 18 个标准 MP3（128kbps / 44.1kHz / 单声道）
    bgm.mp3         敲门声
    voice1-6.mp3    王奶奶：开场白 + 3 句应答 + 兜底 + 撤退
    voice7-12.mp3   快递员：开场白 + 3 句应答 + 兜底 + 撤退
    voice13-17.mp3  维修工：开场白 + 2 句应答 + 兜底 + 撤退
  app.py            一键启动器（Windows 课堂用，可选）
  tts_server.py     本地语音服务（Edge TTS，可选）
  启动网页.bat      双击它就能用（可选）
  使用说明.txt      本文件

二、上传到 GitHub Pages（让所有人都能打开）
  前提：有一个 GitHub 账号（没有就去 github.com 免费注册）。
  1. 登录 github.com，点右上角「+」→「New repository」。
  2. Repository name 随便起一个英文名，比如 home-safety-kids；
     选中 Public，其它保持默认，点「Create repository」。
  3. 创建后页面中间有一行小字「uploading an existing file?」，
     点它；或者直接按上传文件的链接。
  4. 把这个文件夹里的【全部内容】拖进去：
     index.html 一个文件，
     audio 整个文件夹（拖进去后确认里面有 18 个 mp3）。
     底部点「Commit changes」。
  5. 点仓库的「Settings」→ 左侧「Pages」→
     Source 选「Deploy from a branch」，Branch 选 main、目录选 /(root)，保存。
  6. 等 1-2 分钟，刷新 Pages 页面，会出现绿色链接，类似
     https://你的用户名.github.io/home-safety-kids/
     把这个链接发给任何人，手机、电脑都能直接打开。
  注意：
    · index.html 和 audio 文件夹必须在同一个仓库根目录，不能只传 html。
    · 如果手机上麦克风用不了，是正常的（浏览器只在 https 下开放麦克风），
      手机可以打字回答；电脑上用「一键启动包」方式打开才有麦克风。

三、开启「语音识别」（第一次用要先配置）
  语音识别接的是火山引擎「豆包流式语音识别」，走国内服务器，Chrome / Edge 都能用，
  不再依赖谷歌。有两点必须注意：

  【第 1 点：必须用「启动网页.bat」启动】
    火山引擎新版识别接口（v3）用 X-Api-App-Key / X-Api-Access-Key /
    X-Api-Resource-Id 这三个请求头鉴权，而浏览器出于安全根本不让你设置
    自定义请求头。所以必须由本地服务（tts_server.py）建连接、补请求头，
    网页再通过它转发。
      ✅ 正确：双击「启动网页.bat」→ 浏览器打开 http://127.0.0.1:8000/
      ❌ 错误：双击 index.html（没有代理，识别用不了，只能打字）
    直接上传到 GitHub Pages 的话同理——只能听声音、打字回答，没有麦克风识别。

  【第 2 点：Resource ID 必须和控制台开通的一致】
    1. 打开 https://console.volcengine.com 登录火山引擎；
    2. 找到「语音技术」，创建应用并开通「流式语音识别」；
    3. 记下【AppID】【Access Token】和【Resource ID / 服务版本】；
    4. 打开网页 → 右上角「设置」，填 AppID、Access Token，并在
       Resource ID 下拉里选对应的那个：
         volc.seedasr.sauc.duration    豆包流式识别 2.0 · 小时版（最常见）
         volc.seedasr.sauc.concurrent  豆包流式识别 2.0 · 并发版
         volc.bigasr.sauc.duration     豆包流式识别 1.0 · 小时版
         volc.bigasr.sauc.concurrent   豆包流式识别 1.0 · 并发版
       点「保存」，设置面板底部会显示「本地识别代理已就绪」即正常。
    填错版本就是「错误码 198 / no available instances」最常见的原因。
    程序遇到 198 会自动重试 2 次；仍失败会直接把排查要点显示在页面上。

四、希沃白板 / 教室电脑上用
  方法一（推荐，麦克风也能用）：
    把整个文件夹拷贝到教室电脑，双击「启动网页.bat」，
    等黑窗口出现本地服务已启动，浏览器自动打开页面。
  方法二（最省事，只要声音）：
    直接双击 index.html，点屏幕上大大的「点击开始」按钮，
    敲门声、角色语音都能播放；此时麦克风用不了，用打字回答。

五、手机上用
  按上面的方法传到 GitHub Pages（或任何 https 空间），
  手机浏览器打开链接，点「点击开始」即可（可听声音、打字回答）。

六、常见问题
  Q: 打开的页面只有文字没有声音？
  A: 90% 是 audio 文件夹没跟着一起拷贝。页面里引用的是相对路径
     audio/bgm.mp3、audio/voice1.mp3，缺 folder 就 404。
     请把整个文件夹一起操作。
  Q: 提示「音频格式不被支持」？
  A: 本文件夹里的 mp3 已全部重做成标准 MP3（128kbps/44.1kHz），
     主流浏览器都能放。若仍看到这句，说明 audio 文件夹又没到位，
     或浏览器太老——换 Edge / Chrome 最新版试试。
  Q: 点麦克风提示「连不上本地识别代理」？
  A: 说明你是双击 index.html 打开的。识别必须经本地服务转发请求头，
     请双击「启动网页.bat」，用 http://127.0.0.1:8000/ 打开页面。
  Q: 提示「错误码 198 / no available instances」？
  A: Resource ID 和控制台开通的服务版本不一致，或服务到期、并发占满。
     到「设置」里把 Resource ID 改成控制台显示的那个（见上文第三部分），
     并确认服务状态是「已开通 / 运行中」。程序已内置 2 次自动重试。
  Q: 麦克风点了没反应？
  A: 1) 必须用 http://127.0.0.1:8000/ 或 https 打开（双击 html 文件时
        浏览器不允许用麦克风）；
     2) 地址栏右侧的麦克风图标，选「允许」；
     3) 确认已在「设置」里填好火山引擎的 AppID 和 Access Token。
  Q: 提示「鉴权失败 / 401 / 403」？
  A: AppID 或 Access Token 填错了（Token 不要带空格、不要带 Bearer 前缀），
     到控制台重新复制一份。
  Q: 没有大模型 API Key 能玩吗？
  A: 能。不填 Key 时用内置话术演练，流程完整；填了火山引擎方舟的
     Key 后，回答才由大模型实时生成（点页面上的「设置」填）。
